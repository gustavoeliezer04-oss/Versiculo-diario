# Versículo Diário

Aplicativo Android nativo para exibir um versículo bíblico diário sobre uma foto escolhida pelo usuário, aplicando o resultado exclusivamente à tela de bloqueio.

## Estado do projeto

Primeira etapa: estrutura Android, seleção de foto, pré-visualização e aplicação manual na tela de bloqueio. A atualização diária e a personalização serão implementadas em etapas seguintes.

## Requisitos
- Android 8.0 (API 26) ou superior.
- Kotlin + Jetpack Compose.
- Nenhuma notificação é necessária.

## Compilação
O projeto terá uma rotina do GitHub Actions para gerar um APK de depuração.
