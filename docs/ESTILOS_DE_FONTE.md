# Fontes do Versículo Diário

## Famílias disponíveis no Android

A primeira versão usa famílias de fonte do próprio sistema Android, sem copiar arquivos proprietários para o APK:

- Serif: aparência clássica, adequada a textos longos.
- Sans-serif: visual simples e leitura limpa.
- Sans-serif-medium: peso intermediário para destaque.
- Monospace: estilo de largura fixa, opção alternativa.

Essas famílias não são arquivos de fonte independentes empacotados pelo projeto; são fontes disponibilizadas pelo sistema operacional. A renderização exata pode variar entre fabricantes e versões do Android.

## Próxima etapa

Adicionar prévia e controles de família, tamanho, peso, cor e posição do texto. Fontes externas como Lora, Merriweather, Roboto e Open Sans só devem ser empacotadas depois de incluir os arquivos OFL/Apache correspondentes e os créditos exigidos.
